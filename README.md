# 千牛铺货助手（1688上淘）

自用桌面工具，专攻 **1688 → 淘宝（千牛）** 一个方向：采集1688商品 → 自动转换（标题清洗/违禁词/价格策略/品牌处理）→ 千牛自动上架（直接上架或放入仓库）。

## 界面结构

顶栏（当前店铺 + 采集号状态 + 今日上传进度 + 快捷入口），左侧工具列表分 3 组：

| 分组 | 工具 |
|---|---|
| 采集工具 | 链接采集 / 关键词采集 / 全店采集 / 采集配置 |
| 上货管理 | 上传列表 / 上传配置 / 上传记录 |
| 辅助工具 | 店铺管理 / 采集账号 / 工作台 / 系统日志 |

**实时进度**：所有长流程（采集/验证店铺/同步后台/添加列表/上传）在右下角显示进度卡片——标题+百分比+当前步骤详情，完成自动变绿消失，失败变红停留，多个任务同时进行会层叠显示，不用来回翻日志。

## 二、首次使用流程（按顺序）

### 1. 采集账号（左侧「采集账号」）

- 添加 1~N 个「1688采集账号」→ 扫码登录，多号自动轮换更稳
- 1688 采集窗口默认**后台静默**运行（不弹窗），遇到滑块验证才自动弹出置顶，拖动完成后自动继续并重新隐藏

### 2. 店铺管理（左侧「店铺管理」，千牛/淘宝卖家后台）

- 添加「商家账号」→ 扫码登录（上传商品用此登录态，登录后保存在本机）
- 点「**同步运费模板/退货地址**」：软件自动进千牛卖家后台，抓取你的运费模板列表和退货地址列表
- 上传时自动选用同步到的模板/地址，**无需手动填写名字**

### 3. 采集配置（集中管理采集参数）

「采集配置」页统一设置，保存后对三种采集方式生效：

- **采集筛选**：只采集一件代发货源（推荐）/ 只采集1688严选 / 默认价格区间
- **图片下载**：下载主图（勿关）/ 下载详情图 / 主图数量（1~5）/ 详情图数量（0~60）
- **采集节奏（防限流）**：单次采集页数上限 / 翻页间隔秒数（随机区间）/ 详情页等待秒数
- **失败处理**：空结果自动重试（1688偶发限流返回0条）/ 重试次数

### 4. 采集商品（三种方式任选）

- **链接采集**：粘贴1688宝贝链接，一行一个，批量采集
- **关键词采集**：输入关键词 + 页数，按搜索结果采集（中文正常，支持价格/一件代发筛选）
- **全店采集**：粘贴1688店铺链接 → 点「验证店铺」→ 勾选分类 → 按分类采集；页面底部有「最近采集的店铺」历史记录，可一键重采

采集到的商品以卡片展示 → 勾选 → **「添加到上传列表」**

### 5. 上传配置（务必先配，可保存复用）

- **基础设置**：上传方式（直接上架 / 放入仓库，推荐先仓库验证）、商家编码（推荐用1688宝贝ID）、类目关键词、库存、**窗口模式**（后台静默=需要人工时才弹窗 / 始终显示窗口）
- **价格设置**：采集价格（原价/区间最高价）、加价模式（百分比/固定/阶梯）、保底利润、尾数规则、**低于淘宝限价时抬价或跳过**（可设最低限价金额）
- **标题与品牌**：标题前后缀、清除词、品牌处理（改 other/其他 推荐）、违禁词
- **图片设置**：主图数量、详情图数量、主图追加到详情首、**运费模板下拉（同步自千牛后台）**、**退货地址下拉（同步自千牛后台）**
- **风控节奏**：每日上传上限、最小/最大间隔秒、上传时段窗口

### 6. 上传列表 → 开始上传

- 「上传列表」勾选商品 → 「开始上传」（或顶部「开始上传」）
- 发布页从**千牛工作台**进入（卖家后台确认登录态后再进发布页），全程后台静默，遇到验证才弹窗
- 「上传记录」页查看每条结果与失败原因，失败商品一键重新上传

## 三、强烈建议的第一次联调

## 四、风控与合规（务必看）

- 2026年淘宝严打"无货源搬运"：批量铺他人商品可能被下架/扣分/封店
- 软件默认 **只采集1688"一件代发/分销"货源**（可关，强烈建议保留）
- 控节奏：每日限量默认30、随机间隔45~180秒、分时段上架，别调太猛
- 标题自动清理违禁词/极限词（广告法），可在配置里补充行业词
- 上架后人工抽查前几个商品再放手

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 采集弹"1688滑块验证" | **正常现象**。窗口自动弹出置顶，拖动滑块完成，完成后自动隐藏继续 |

| 价格不对/被跳过 | 商品库售价列可改；调价格策略；「低于限价跳过」配置会导致低价品被跳过 |
| 想重采某店 | 全店采集页→「最近采集的店铺」一键重采 |

## 七、技术说明（开发者参考）

- Electron 33 + 纯JS，数据全本地，无外部服务
- 账号会话隔离：每账号独立 session partition（persist:qnp-*）
- 发布自动化：React 受控组件原生 setter 填值 + CDP `DOM.setFileInputFiles` 传图
- 采集：登录态浏览器滚动翻页 + `__INIT_DATA__` / 点击捕获多级提取
- 变频价格：`price.source` 原价/区间最高价；`price.floorPrice` 淘宝最低限价，低于时抬价或跳过
